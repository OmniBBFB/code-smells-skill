# 膨胀问题：S01—S05

这些规则评估理解和修改成本。长度、字段数、参数数是筛选线索，不是诊断阈值。

## S01 长方法 · Long Method

- **定义：** 一个方法包含难以辨认或独立修改的多个阶段，读者需同时记住过多实现细节。
- **候选信号：** 验证、计算、持久化、通知混杂；深层控制流；注释在划分阶段；局部变量跨多个阶段交织。
- **必要证据：** 阅读完整方法，指出具体的阶段或认知负担、各阶段输入输出及可命名边界。仅因代码长、算法复杂或有多行数据不能定性；解释怎样的修改需要跨阶段理解。
- **合理例外：** 清楚的声明式表格、生成代码、具有明确步骤和必要局部状态的算法。提炼后若参数和隐藏状态更复杂，不能视为自动改善。
- **维护影响：** 一个阶段变化牵连其他阶段，测试或理解需要掌握整条流程；指出具体阶段。
- **改善方向：** 提炼有语义名称的阶段，分解表达式或条件；变量严重交织时评估计算对象。保留执行顺序、作用域和副作用。
- **上下文不足：** 只有方法签名或部分函数体时，明确未读到哪些阶段，保留判断。

## S02 大类 · Large Class

- **定义：** 类承担多组缺少共同职责的状态和行为，使独立变化必须在同一实现中协调。
- **候选信号：** 字段和方法形成互不相用的簇；同时包含计价、数据库、展示或调度实现；不同调用者仅使用各自子集。
- **必要证据：** 阅读成员及相关调用者，列出至少两组具体职责或状态簇及不同约束。类很长不充分；多个方法属于同一模型也不充分。
- **合理例外：** 完整但内聚的领域对象、接口声明、生成模型、对外提供统一操作且内部职责已委托的门面。
- **维护影响：** 独立规则、基础设施或展示变化进入同一个类，增加理解与耦合范围。
- **改善方向：** 按职责提炼类或接口，通过组合协调；避免按任意行数拆成碎片。
- **上下文不足：** 仅有成员名或一部分实现时，报告候选并查阅其实现和状态使用。

## S03 基本类型偏执 · Primitive Obsession

- **定义：** 领域概念的约束、单位、身份或行为被基本类型与约定隐含表达，客户端反复解释这些约定。
- **候选信号：** 金额与币种成对传递、字符串状态码参与行为、位置元组承载地址、同种校验散落多处。
- **必要证据：** 找到具体领域语义、约束或单位及其解释位置，说明为何现有类型不足以保护规则。一次字符串参数或简单数字不是充分证据。
- **合理例外：** 原始解析输入、明确的外部传输协议、无额外规则的标识值、一次性局部计算；已有枚举或值对象可充分表达概念。
- **维护影响：** 单位、顺序或允许值混淆；规则变化要求多个客户端重新理解原始表示。
- **改善方向：** 按实际规则引入值对象、枚举、命名记录或集中验证；在边界转换，不为每个标量制造类。
- **上下文不足：** 不知道字段单位、允许值或调用约定时，先查领域契约，不能仅凭类型名称判错。

## S04 长参数列表 · Long Parameter List

- **定义：** 方法的输入组合难以理解或正确构造，参数暴露了过多细节、混合不同职责或形成易错协议。
- **候选信号：** 大量位置参数、多个布尔开关、参数经常一起传递、调用处重复拆解同一对象。
- **必要证据：** 阅读签名与至少一个调用或完整契约，指出分组、顺序歧义、互斥组合或职责混合的具体成本。数量不是必要或充分条件。
- **合理例外：** 稳定外部 ABI、框架回调、清楚且独立的科学函数参数、关键词专用参数的内聚配置。
- **维护影响：** 易错调用、非法组合，或者增加某一概念的数据时要同步调整多处签名。
- **改善方向：** 传递已有完整对象、引入有明确语义的参数对象、拆分不同操作。不要把无关参数塞进无结构字典来掩盖问题。
- **上下文不足：** 只有签名而没有语义或调用者时，报告输入可疑点，核实约定后再定性。

## S05 数据泥团 · Data Clumps

- **定义：** 同一组有共同语义的数据在多个位置结伴出现，却没有表达其整体概念与一致性约束。
- **候选信号：** 多个签名重复 host/port/tls；字段组合在对象和函数之间整体复制；修改其中一项通常涉及同组数据。
- **必要证据：** 对比实际出现位置，确认它们属于同一概念而非碰巧同类型；指出共同来源、整体传递或共同约束。不能只比变量名。
- **合理例外：** 不同领域恰好具有相同字段、受固定协议限制的序列化边界、清楚的一次性局部数据。
- **维护影响：** 组内增加字段或改变规则会波及多处；组合可能不一致。
- **改善方向：** 提炼值对象或参数对象，集中组内规则；对外协议继续按需展开。
- **上下文不足：** 只见单一出现位置或不知道各组含义时，寻找其他声明和调用，仍无法确认则保留判断。
