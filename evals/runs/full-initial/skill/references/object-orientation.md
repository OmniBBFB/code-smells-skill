# 面向对象使用问题：S06—S09

这些规则同样适用于函数、代数数据类型或动态分派；多态不是所有分支的默认目标。

## S06 switch 判断 · Switch Statements

- **定义：** 相同的类型判别驱动多个分散的行为分支，使新增类型必须同步修改多个决策点。
- **候选信号：** 多处 switch/match/if-elif 判断同一类型码；每个类型的相关行为散落在不同函数。
- **必要证据：** 对照具体判别字段和分支，确认类型具有共同概念及分散的行为，解释新增类型的同步修改路径。单个 switch 不构成充分证据。
- **合理例外：** 解析器、协议解码、穷尽匹配代数数据类型、稳定局部映射、边界处一次性类型分派。编译器能检查新增变体的穷尽性时也要考虑其收益。
- **维护影响：** 新增类型或更改规则时遗漏某个分支；集中到一个统一映射也可能足够。
- **改善方向：** 按变化轴选择策略、多态或集中分派表；不要把简单映射扩展为不必要的类体系。
- **上下文不足：** 只有一个分支点且不知道其他用途时，定位同一判别字段的使用；无法看到范围外代码时保留判断。

## S07 临时字段 · Temporary Field

- **定义：** 对象字段只为某次操作或少数阶段服务，在正常状态下无意义，给对象引入隐藏的生命周期协议。
- **候选信号：** 大量字段先置空，仅某个方法填充；另一个方法假定已经准备；一次计算的局部结果存成长期状态。
- **必要证据：** 查看初始化、写入和读取路径，明确有效阶段与调用顺序，确认数据是否应跨操作保留。指出没有对应状态模型的协议依赖。
- **合理例外：** 明确的状态机、惰性缓存、可选领域数据、生命周期建模完备的事务会话；空值本身不是坏味道。
- **维护影响：** 未初始化、过期状态或不同调用交叉，导致正确性依赖未显式表达的顺序。
- **改善方向：** 使用局部变量或计算对象；真正存在阶段时通过独立状态类型或明确协议表达。
- **上下文不足：** 看不到写入、读取或生命周期时，报告需核实的状态路径，而非以 None 初始化定罪。

## S08 被拒绝的遗赠 · Refused Bequest

- **定义：** 子类继承的契约对它不成立，需拒绝、忽略或禁用调用者按父类契约可合理使用的能力。
- **候选信号：** 子类对父类正常操作抛“不支持”、空实现或加强前置条件；继承仅为复用一小部分实现。
- **必要证据：** 阅读父类约定、子类覆盖及替换使用路径，指出具体不兼容契约。未使用某个继承方法或覆盖抽象方法不充分。
- **合理例外：** 基类明确允许可选能力及“不支持”结果、抽象扩展点、受约束的框架生命周期。
- **维护影响：** 使用父类型的客户端必须识别特殊子类，或者替换对象后行为违反原约定。
- **改善方向：** 分离能力接口、把共同部分下沉至合适基类，或以组合取代不成立的继承。
- **上下文不足：** 缺少父类契约或替换场景时，先报告疑似拒绝的能力并核实允许行为。

## S09 接口不同的替代类 · Alternative Classes with Different Interfaces

- **定义：** 可互换的同领域能力因偶然的命名、参数或返回接口差异而无法被统一调用。
- **候选信号：** 调用者检查实现类型后换方法名或重排参数；两套本地实现语义等价但接口不一致。
- **必要证据：** 比较实际语义、输入输出、失败和副作用，并查看选择实现的调用者。名称相近不等于可替换。
- **合理例外：** 外部供应商固有协议、语义或生命周期不同的能力、已有适配层保护本地统一契约。
- **维护影响：** 客户端重复适配，新增实现要求更多类型判断。
- **改善方向：** 本地类统一接口或提炼共同契约；外部类用适配器，保留真实语义差异。
- **上下文不足：** 两个方法仅有签名而语义未知时，核实等价性，不能按方法名判断。
